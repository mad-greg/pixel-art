# Project: Kilchberg Isometric Diorama — v12 Graphics, Textures & 60fps Smoothness Overhaul

## Architecture
- **Backend Render Pipeline (`pipeline/`)**: Pure-Python + NumPy/SciPy software 3D isometric rasterizer backed by swisstopo 0.5 m LiDAR (`swissALTI3D` + `swissSURFACE3D`), 3D LOD2 CityGML (`swissBUILDINGS3D`), 10 cm `SWISSIMAGE DOP10`, and MVT vectors. Cached in `/tmp/kilchberg-cache/`. Outputs `24,661 × 10,888` (`0.125 m/px`) 2-level lossless VP8L tile pyramids (`day`, `sunset`, `night`), 10 landmark detail plates (`0.11 m/px`), 16-bit depth/occluder map (`0.50 m/px`), and JSON metadata.
- **v12 Visual Philosophy ("Trust LiDAR, Then Round & Smooth" — `tinyrj.com` benchmark)**:
  - Keep 100% swisstopo geographic fidelity (footprints, heights, terrain, tree locations, road centerlines, all 16 photo-accurate landmarks).
  - Eliminate all 7 noise sources: global 4×4 Bayer checkerboard dithering on solid surfaces, raw noisy 10 cm DOP10 pixels on non-HoC roofs, per-pixel random `p_hash`/`wh_tex`/`micro_1x1` static, nearest-neighbor 0.5 m stair-stepped road/yard/hedge edges, steep-DEM retaining-wall streaks on grass, noisy single-puff trees/spiky voxel hedges, and soft multiplicative outlines.
  - Replace with clean 3–4 step cel-shading, strong warm-sun vs cool-slate shadow contrast, crisp 1.5–2 px dark-ink architectural & foliage outlines (including wall-corner/roof-facet creases and internal multi-lobe tree creases), smooth sub-pixel SDF roads + warm-cream sidewalks + curbs, rounded multi-lobe cloud trees & pillow hedges, and denoised/stylized architectural roofs (preserving Lindt Home of Chocolate authentic roof, Solar PV arrays, and baked `pipeline/signage.py` lettering).
- **Frontend Interactive Viewer (`docs/`)**: Pure Canvas2D HiDPI viewer (`dpr = min(2, devicePixelRatio)`) with unified 60fps `requestAnimationFrame` loop, critically-damped/exponential camera kinematics (`docs/js/camera.js`), async off-main-thread `createImageBitmap` tile pyramid streaming (`docs/js/tiles.js`), optimized 16-bit depth masking (`docs/js/render/depth.js`), cached glow-sprite vignettes (`docs/js/render/vignettes.js`), deterministic 20 Hz simulation with 60fps sub-step interpolation (`docs/js/sim/traffic.js`, `docs/js/sim/pedestrians.js`), and 9-channel shore-strict spatial audio (`docs/js/audio.js`).
- **E2E Verification (`tests/`)**: Python + Node 24 zero-dependency CDP harness (`tests/run_e2e.py`) running 4 tiers (115 existing tests + new v12 smoothness & visual-polish tests).

## Code Layout
- `pipeline/fetch_data.py`, `pipeline/extract_scene.py` — swisstopo download & 0.5 m scene/hedge/roof extraction
- `pipeline/pixel_shader.py`, `pipeline/signage.py`, `pipeline/config.py` — 3D isometric shader, cel-shading, outlines, foliage, signage, landmarks
- `pipeline/render_all.py`, `pipeline/verify_quality.py` — split `--macro-rows` render orchestrator & automated quality gate
- `docs/index.html`, `docs/styles.css`, `docs/app.js` — viewer shell, styles, unified 60fps loop & HUD
- `docs/js/camera.js`, `docs/js/tiles.js` — (new in v12) smooth camera kinematics & async `ImageBitmap` tile pyramid streamer
- `docs/js/render/depth.js`, `docs/js/render/vehicles.js`, `docs/js/render/vignettes.js` — depth occlusion, 3D vehicle sprites, landmark & ambient vignettes
- `docs/js/sim/traffic.js`, `docs/js/sim/pedestrians.js`, `docs/js/sim/schedule.js`, `docs/js/sim/rng.js` — deterministic simulation + sub-step interpolation
- `docs/js/audio.js` — 9-channel shore-strict spatial audio (untouched)
- `docs/assets/**`, `renders/**` — rendered overviews, 2-level WebP tile pyramids, 10 detail plates, 16-bit depth PNG
- `tests/run_e2e.py`, `tests/lib/cdp_harness.mjs`, `tests/tier*.{py,mjs}` — 4-tier E2E test suite

## Interface Contracts

### `docs/app.js` ↔ `docs/js/camera.js`
- `createCameraController(opts)` returns `{ state, isMoving(), isAnimating(), setView(u, v, scale, opts), panBy(dxDev, dyDev), beginDrag(x, y, nowMs), moveDrag(x, y, nowMs), endDrag(nowMs), wheelZoom(deltaY, deltaMode, ctrlKey, cxDev, cyDev), flyTo(targetU, targetV, targetScale, opts), setHeldKey(code, down), clearHeldKeys(), followStep(desiredX, desiredY, dt), step(dt, nowMs, bounds), cancelMotion(), getTargetScale() }`.
- `state` exposes `{ offsetX, offsetY, scale, targetScale, vx, vy, moving }`.
- Instant/deterministic contract: when `fixedAnimTime !== null` or `prefersReducedMotion` is active, `setView`/`flyTo`/`wheelZoom` settle immediately without multi-frame spring lag (`T3.07`).
- Settle contract: drag inertia (`τ = 325 ms`, stop threshold `< 0.02 px/ms` or `< 12 px/s`) and wheel zoom (`τ = 80 ms`, stop threshold `|ln(target/s)| < 0.0005`) settle cleanly within `< 650 ms` (`waitForCameraSettled` budget is `950 ms`).

### `docs/app.js` ↔ `docs/js/tiles.js`
- `createTileManager(opts)` returns `{ setMode(mode), setManifest(mode, manifest), drawTiles(ctx, view, opts), getStats(), clearAll() }`.
- Uses `fetch() → blob() → createImageBitmap(blob)` (fallback `HTMLImageElement.decode()`), `MAX_INFLIGHT = 8`, `AbortController` for stale off-viewport tiles, `MAX_CACHED_TILES = 128` with `bmp.close()` on LRU eviction.
- `T2.FA3.11` contract: NEVER requests L2 tiles at Fit overview; bounded prefetch (velocity-directed / 1-tile ring) keeps `Fit → 1:1` L2 fetches within `1..48`.
- `T3.07` contract: tile crossfade (`120 ms`) is bypassed (`alpha = 1`) when `fixedAnimTime !== null`.
- `getStats()` returns `{ cacheSize, inflight, queued, decodedCount }`.

### `docs/app.js` ↔ `window.__dioramaDebug` (E2E Contract)
- Preserve ALL 13 existing keys (`mode`, `zoom`, `scale`, `u`, `v`, `offsetX`, `offsetY`, `dpr`, `tileLevel`, `tilesLoaded`, `animEnabled`, `animTime`, `simStats`, etc.).
- Add additive `frameStats: { fps, p95FrameMs, lastFrameMs, droppedFrames, tileInflight, tileCacheSize, camSpeedPxPerSec, rafActive }`.

### `pipeline/pixel_shader.py` ↔ `pipeline/verify_quality.py` ↔ `tests/tier2_v12_visuals.py`
- Tile pyramid dimensions remain `24,661 × 10,888` (`0.125 m/px`), 275 L2 + 78 `z1` lossless VP8L WebPs per preset (`day`, `sunset`, `night`), `<= 256` unique colors per interior tile, macro-tile seam ratio `< 1.35`, every tile `< 500 KB`, total `docs/` `< 300 MB`.
- Guardrails: Lindt Home of Chocolate roof (`id_lindt_hoc`, `base_w=0.95`), Solar PV (`is_pv`), baked isometric signage (`pipeline/signage.py`), St. Elisabeth white-concrete tower with NO clock, 4-petal white-flower Kilchberg flag, spotless Lake Zurich shoreline, smooth Bendlikon viaduct, flat SBB rail bridges, opaque train/bus roofs, slow SUPs (~1.6 m/s), no paragliders, DEM-exact edge-to-edge roads.
